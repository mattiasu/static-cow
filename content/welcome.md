## Features

- 📝 Write posts Markdown
- 🏗️ Modular architecture
- ⚡ Fast static site generation
- 🏷️ Tag support
- 📊 Reading time estimates
- 🚀 Easy to deploy

## How to Add Posts

Simply create a new Markdown file in the `content/` directory with YAML frontmatter:

```markdown
---
title: Your Post Title
date: 2026-05-15
category: Your Category
author: Your Name
intro: Your short intro text
tags: tag1, tag2
---

# Your content here
```

## Next Steps

1. Edit posts in `content/`
2. Customize styling in `src/styles.css`
3. Build with `npm run build`
4. Deploy the `dist/` folder to your hosting

Enjoy blogging! ✨
